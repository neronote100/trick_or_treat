# 🎄 クリスマス用サムネイル・共通プロンプト（任意）
参加者が自分の記事の世界観を保ちながら、ツリーでも映えるサムネイルを作るための補助プロンプトです。**使用は任意**で、既存のnoteサムネイルでも参加できます。

```text
私のnote記事の内容に合う、クリスマス企画用の高品質なサムネイルを1枚作成してください。
比率は横長16:9。記事のテーマは【ここに入力】。伝えたい感情は【ここに入力】。
この作品固有の意味を持つモチーフをひとつ主役に選び、クリスマスの
柔らかな光、冬の夜空、金色と深緑の上品な装飾で包んでください。
小さな円形のオーナメントとして切り抜かれても、中央の主役が判別できる構図。
四隅に文章や重要なモチーフを置かない。画像の中心60%に主役を収める。
テンプレートに統一しすぎず、参加者ごとの色・雰囲気・物語を守る。
文字は原則なし。必要なら記事タイトルの短いフレーズだけを大きく配置する。
商標や既存のキャラクターを無断で模倣せず、オリジナルの表現とする。
```

サイト側では既存の横長サムネイルも、円形に切り抜き、金縁とリボンでオーナメント化します。
